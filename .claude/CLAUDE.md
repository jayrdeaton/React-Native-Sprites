# @tastic/sprites

Shared visual effects for React Native games — an SVG+Reanimated `Fireworks` celebration burst (ported from Hangman), a Skia+Reanimated `GravityWell` particle-swirl marker (ported from BoxHockey/Swirlio's near-duplicate implementations), a Skia+Reanimated `shapes` subpath (`ObstacleRect`, `GoalPost`, `Disc`, `CelebrationRings`, `MysteryPickup` — reconciled from BoxHockey/AirHockey/Pong/LightCycles/Snake's near-duplicate board dressing), and a Skia+Reanimated `hockey` subpath (`ZoneLine`, `FaceoffCircle`, `GoalDoorFlash`, `ScoreWedges` — reconciled from BoxHockey/AirHockey's near-duplicate two-goal rink chrome). Part of the `@tastic` package ecosystem.

Four subpath exports (`./fireworks`, `./gravity`, `./shapes`, `./hockey`), deliberately no root `"."` export — `Fireworks` and the other three have mutually exclusive optional native-rendering peers (`react-native-svg` vs `@shopify/react-native-skia`), and a shared barrel would force Metro to resolve both for any consumer. `gravity`, `shapes`, and `hockey` are all Skia-only (no peer-isolation reason to split them from each other), kept as separate subpaths anyway since they're independently reusable concepts — a consumer wanting only `ObstacleRect` shouldn't need to know `GravityWell` exists. `hockey` specifically holds genre-specific rink chrome (BoxHockey/AirHockey only) rather than the more generic board dressing `shapes` holds — kept out of `shapes` so a non-hockey consumer of that subpath never sees hockey-only concepts like a faceoff circle or a goal door.

`shapes`' and `hockey`'s exports are deliberately thin, presentation-only wrappers — props in, pixels out, only ever local/cosmetic animation state (a ring's opacity, a flash's timing). None of them know what a "player," "score," or "goal" means as a game concept; a caller resolves per-player color before handing it in as a plain `color` prop. `Disc`'s `opacity`/`ringOpacity`, `CelebrationRings`' internal shared values, and `GoalDoorFlash`'s internal shared values all follow GravityWell's own "SharedValue in, SharedValue out" discipline — see each component's own doc comment. `hockey`'s own interactive/game-rules exclusions (BoxHockey's faceoff countdown pulse, its live-target tint, its ready-check breathing ring) are documented on `FaceoffCircle`'s own doc comment — real game state that stays app-local, layered by the caller around the static shape this package renders.
